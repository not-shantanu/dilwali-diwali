# Diwali Party Invitation

Mobile-first interactive invitation built with React, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Customize party details

Edit `src/data/invite.ts` for date, time, address, maps link, dress code, and vibe copy.

RSVP responses are saved in the browser via `localStorage` (`diwali-party-rsvp`).
